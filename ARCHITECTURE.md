# ASHEN WORLD — Техническая архитектура (ARCHITECTURE.md)

## 1. Общие принципы
Архитектура **ASHEN WORLD** построена вокруг игрового движка **Phaser 3 (v3.88.2)** и **TypeScript** со сборщиком **Vite**. Приложение работает полностью на стороне клиента без внешних серверов и баз данных.

На **Этапе 2** архитектура переведена с бокового платформера на классическую **2D RPG с видом сверху под углом (псевдоизометрическая 3/4 перспектива)**:
* гравитация мира отключена (`gravity: { x: 0, y: 0 }`);
* реализовано свободное 8-направленное перемещение с векторной нормализацией диагональной скорости (`normalizeMovementVector`);
* внедрена динамическая сортировка глубины отрисовки (`computeYSortDepth(footY)`) для реалистичного обхода деревьев, колонн, арок, обелисков и NPC спереди и сзади;
* схема сохранений `SaveManager` обновлена до версии `v2` (`SAVE_SCHEMA_VERSION = 2`) с поддержкой RPG-характеристик героя (`HeroStats`), изученных объектов мира (`discoveredInteractables`) и бесшовной миграцией валидных сохранений `v1 -> v2`.

## 3. Движение в 8 направлениях и Y-Sorting
* **Векторная нормализация (`normalizeMovementVector`):** Ввод с клавиатуры (`WASD` / стрелки) и виртуального джойстика приводится к вектору `(vx, vy)` с ограничением `Math.hypot(vx, vy) <= 1.0`. При диагональном движении скорость составляет ровно `240 px/s` (а не `240 * √2`), сохраняя плавность аналогового отклонения стика.
* **8 румбов ориентации (`resolveFacingDirection`):** По углу `Math.atan2(vy, vx)` определяется одно из 8 направлений (`s`, `se`, `e`, `ne`, `n`, `nw`, `w`, `sw`), управляющее выбором анимации `hero-idle-{dir}` или `hero-walk-{dir}`.
* **Сортировка глубины (`computeYSortDepth`):** Глубина отрисовки каждого вертикального объекта и героя вычисляется по координате точки опоры у земли (`Math.round(footY * 10) + layerBias`). Коллайдеры объектов расположены компактно у их основания, что позволяет герою свободно заходить за кроны деревьев, колонны, арки и обелиски или проходить перед ними.

## 4. Система сохранений (IndexedDB v2 + LocalStorage)
* **IndexedDB (`ashen_world_db` / `saves`):** хранит запись `SaveRecord` версии `v2`:
  * координаты `x, y` в пределах мира `2400×1600` и одно из 8 направлений `facing`;
  * `heroStats`: `level`, `xp`, `xpToNext`, `hp`, `maxHp`, `mana`, `maxMana`;
  * `discoveredWaystones` (до 3 обелисков) и `discoveredInteractables` (до 5 NPC и объектов мира);
  * `playTimeSeconds`, `savedAt` и 32-битную контрольную сумму **FNV-1a** (`checksum`).
* **Обратная совместимость (`v1 -> v2`):** При обнаружении валидной записи Этапа 1 (`version: 1`, направления `'left' | 'right'`) `validateAndMigrateSave()` проверяет её контрольную сумму `computeLegacyV1Checksum()`, конвертирует направление (`'left' -> 'w'`, `'right' -> 'e'`), адаптирует координаты к безопасному проходимому участку карты `2400×1600` через `resolveSafeWalkablePosition()` и пересчитывает контрольную сумму `v2`.
